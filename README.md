# Studio Semestre Aperto 2026

App locale per preparare il **Semestre Aperto** (Biologia, Chimica e propedeutica biochimica, Fisica) con:

- **Triage** — ogni cartella si apre con 5 domande; codice rosso / giallo / verde
- teoria estesa + sezione **Per capire meglio** (spiegazione semplice)
- argomenti extra correlati dove servono
- calendario adattivo fino al **30 novembre 2026**
- simulazioni d’esame (31 domande, 50 minuti)

## Avvio

```bash
npm install
npm run dev
```

Apri l’URL mostrato da Vite (di solito `http://localhost:5173`).

I progressi restano nel browser (`localStorage`). Usa la pagina **Dati** per esportare/importare un backup JSON.

I PDF ufficiali sono in `files/`.
